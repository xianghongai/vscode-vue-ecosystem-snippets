# Changelog / 更新日志

## 1.0.0

- Initial Vue 3 ecosystem snippet collection for `.vue`, TypeScript and JavaScript.
- Cover VueUse and its integrations, TanStack Vue Query and Pinia Colada side by side, VeeValidate with Zod, Vue I18n, Unhead, composable patterns, class names and tests.
- Include five cross-library recipes and complete single-file component templates.
- 首个 Vue 3 生态片段集，覆盖 `.vue`、TypeScript 与 JavaScript。
- 包含 VueUse 及其集成层、并列提供的 TanStack Vue Query 与 Pinia Colada、VeeValidate + Zod、Vue I18n、Unhead、组合式函数模式、类名处理与测试。
- 另含五个跨库组合场景与完整单文件组件模板。
